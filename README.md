# ⚡ Wiwi Web — Wiwi Energía

Portal web oficial y *landing page* informativa de **Wiwi Energía**. Este proyecto sirve como escaparate digital para dar visibilidad a la iniciativa y ofrecer un canal directo y sencillo donde los usuarios pueden subir su documentación o facturas en formato PDF para su posterior estudio interno.

---

## 🎯 Propósito del proyecto

El objetivo principal de **Wiwi Web** es actuar como punto de contacto inicial entre el cliente y nuestro equipo de análisis energético:

1. **Presencia e información:** Presentar el proyecto Wiwi Energía de forma clara, transparente y accesible para que los usuarios conozcan qué hacemos.
2. **Recepción de documentación (PDF):** Facilitar un formulario web donde los usuarios puedan adjuntar sus facturas o documentos en formato `.pdf`.
3. **Estudio interno:** La web funciona exclusivamente como frontis de captación (sin procesos automatizados ni IA). Una vez recibido el archivo PDF, el equipo de Wiwi Energía lo revisa y realiza un estudio interno personalizado.

---

## 🛠️ Flujo de funcionamiento

```text
[ Usuario ] ──(Sube factura en PDF)──> [ Wiwi Web (Front-end) ]
                                                  │
                                       (Recepción del archivo)
                                                  ▼
                                 [ Estudio interno — Equipo Wiwi Energía ]
